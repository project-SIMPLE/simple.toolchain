# SIMPLE Unity Template VR

A Unity 6 project template for building VR applications connected to [GAMA](https://gama-platform.org) simulations via the [SIMPLE WebPlatform](https://github.com/project-SIMPLE/simple.webplatform).

## Requirements

- **Unity Editor 6000.3.8f1** — exact version required
- Modules: **Android Build Support** (with OpenJDK + Android SDK & NDK Tools), **Visual Studio Code**

> **Windows:** verify that `Assets/Plugins/websocket-sharp.dll` is present before building for Windows.
